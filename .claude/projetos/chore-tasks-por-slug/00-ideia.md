# chore-tasks-por-slug — ideia

Chore de higiene no canônico: organizar issues locais em `tasks/{slug}/NN-*.md` (mesmo slug
de `.claude/projetos/{slug}/`, sem flat na raiz) e, na mesma branch, fechar a fatia UX
**task 66** — aviso explícito ao usuário no enter SDD (`harness-brainstorm` / `harness-build`)
de como abrir o painel live (`live.html` / `/fluxo-live`), com Dev Loop fora do MVP.
